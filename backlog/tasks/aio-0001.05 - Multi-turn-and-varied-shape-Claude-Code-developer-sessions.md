## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Every session in `apps/dev-workstation/bin/dev-session` is one `claude -p` call at `--effort low` with a $0.30 budget, so every conversation has exactly one user message and a similar length. Real sessions include follow-ups, corrections ("no, the other file"), a change of mind, abandoned work and the occasional long task. Gateway spend caps must keep bounding cost.
<!-- SECTION:DESCRIPTION:END -->

- [ ] #3 Agent Observability shows multi-turn conversations for the developers, and the dev_session result line records the turn count
