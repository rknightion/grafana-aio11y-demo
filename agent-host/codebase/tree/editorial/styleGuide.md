# Touchline Times style guide (previews)

- Intro line, then one short paragraph per team, then a closing head-to-head or form stat.
- Pull team news and head-to-head record from the demo MCP tools, never invent a scoreline or
  injury that the tools didn't return.
- Punchy, not a stats-page recitation - this runs on the site, not in a data table.
- Coastal/local derbies can run livelier; midtable Tuesday-night fixtures should not be oversold.
- Any preview that mentions odds or an offer needs the 18+ / responsible-gambling line - see
  offers/wording.js for approved phrasing.
- Around 200-300 words for a full preview; a "blurb" for a friendly/preseason game is ~100 words.
